# آزمایشگاه توسعه حساب صراف

این قابلیت در شاخه آزمایشی feature/creator-preview-lab-2026-10-30 پیاده‌سازی شده و هنوز وارد شاخه انتشار یا سایت زنده نشده است.

## محل دسترسی
تب «آزمایشگاه توسعه» در پنل سازنده قرار دارد. این تب از تب «پیش‌نمایش چیدمان موبایل» و محیط «آزمایش فروش» موجود جداست.

## مرز ایمنی نسخه اولیه
- داده‌ها نمونه و غیرواقعی هستند.
- وضعیت عملیات فقط در حافظه همان صفحه React نگهداری می‌شود.
- هیچ اتصال یا فراخوانی به Supabase، APIهای مالی، حساب‌های واقعی یا ابزار مرور دیتابیس زنده انجام نمی‌شود.
- اطلاعات پس از بارگذاری مجدد صفحه باقی نمی‌ماند.
- هیچ دکمه‌ای برای انتشار مستقیم در نسخه اصلی وجود ندارد.
- اجرای عملیات در این محیط فقط برای نمایش جریان رابط کاربری است و ثبت حسابداری واقعی محسوب نمی‌شود.

## بخش‌های نمایشی
نمای کلی، مشتریان، معاملات ارز، صندوق و بانک، حواله‌ها، خدمات آنلاین، گزارش‌ها، امنیت و دسترسی، و کار آفلاین/همگام‌سازی. تغییر حالت دستگاه بین لپ‌تاپ/دسکتاپ و موبایل در همان پیش‌نمایش ممکن است.

## محدودیت‌ها و گام‌های بعدی
این نسخه یک نمونه تعاملی رابط کاربری است، نه موتور مالی کامل. پیش از اتصال هر قابلیت به داده یا خدمت واقعی باید محیط backend جداگانه، داده آزمایشی مستقل، کنترل دسترسی سمت سرور، آزمون‌های حسابداری و مسیر بازگشت مستقل ایجاد و بررسی شود. این شاخه به‌تنهایی هیچ تغییری در A1 زنده اعمال نمی‌کند.
